# Как редактировать шаблоны презентаций
## Название типов слайдов
- title*  - название презентации
- section* - название раздела презентации
- slide* - обычный слайд с картинкой или без неё
- table* - слайд с таблицей
- last* - последний слайд

## Название полей
Для редактирования названия полей в PowerPoint нужно нажать ALT + F10 или Home tab -> Drawing group -> Arrange drop-down -> Selection pane
### Для слайдов title*, section*, slide*, table*
- TITLE_FIELD - Заголовок
### Для слайдов title*, section*
- SUBTITLE_FIELD - Подзаголовок
### Для слайдов table*, slide*:
- TEXT_FIELD - текстовое поле с буллитами
- IMAGE_FIELD - картинка
### Для слайда table*
- TABLE_FIELD - Таблица
