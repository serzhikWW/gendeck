# Общие вехи (синхронизация между ролями)
Порядок строгий: следующая веха не начинается, пока не закрыт «выход» предыдущей.

| Веха | Содержание | Кто даёт выход | Критерий |
|---|---|---|---|
| M0 Контракт | `contracts.py` принят командой, репо поднято, шаблоны лежат в `templates/` | все (созвон 30 мин) | каждый может `pip install -e .` и `pytest` зелёный |
| M1 Моки | BA кладёт 2 золотых `DeckPlan` JSON (`data/gold/`), ML2 рендерит их в PPTX без LLM | BA, ML2 | PPTX открывается в LibreOffice |
| M2 Сквозной путь | ingest → LLM → fit → render на шаблоне README, CLI | ML1, ML2, BA | `cli --demo` создаёт PPTX |
| M3 Проверки | fidelity + layout validator + repair-цикл; профиль ИнтерРАО | ML1, ML2, FS, BA | отчёт валидации по золотому набору |
| M4 Продукт | веб-UI с прогрессом, превью, скачиванием; Docker | FS | `docker compose up` работает |
| M5 Р7-Офис | все выходные файлы открыты и отредактированы в Р7 на Astra (или Р7 для Linux) | BA + FS | чек-лист совместимости заполнен |
| M6 Сдача | README, примеры вход/выход, ограничения, демо-прогон | BA | сухой прогон демо без правок руками |

Ежедневно 15 минут: что сделано, что блокирует, какие контракт-вопросы. Любой блокер по контракту решается в тот же день.
