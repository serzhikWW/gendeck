# Чек-лист совместимости с Р7-Офис (Astra Linux)

Совместно: ML2 (рендер), FS (стенд Р7, FS-6), BA (заполнение). Автоматическая часть — `deckgen.renderer.sanity.check_pptx(path)`,
регрессия — `tests/test_pptx_sanity.py`. Ручная часть заполняется на стенде Р7 для каждого файла золотого набора.

## A. Автоматические проверки (каждый рендер, `check_pptx`)
| Код | Что проверяется | Почему важно для Р7 | Статус |
|---|---|---|---|
| `AUTOFIT` | нет `normAutofit`/`spAutoFit` в слайдах, макетах, мастерах, заметках | Р7 пересчитывает автоподбор по-своему → текст «прыгает» | ✅ рендер заменяет на `noAutofit` везде (в т.ч. в макетах шаблона) |
| `FONT` | все гарнитуры = Liberation Sans (кроме ссылок на тему `+mn-*`); шрифты тем major/minor = Liberation Sans | в Astra нет Calibri → подмена шрифта и другие переносы | ✅ рендер переписывает гарнитуры и шрифты тем |
| `NO_FONT_SIZE` | у каждого рана с текстом явный `sz` | кегль не зависит от наследования, одинаков во всех редакторах | ✅ |
| `EMPTY_PLACEHOLDER` | на слайдах нет пустых плейсхолдеров | Р7 показывает «Нажмите, чтобы добавить текст» в режиме редактирования | ✅ удаляются |
| `BROKEN_REL` / `CONTENT_TYPE` | все внутренние связи ведут в существующие части, у каждой части есть content type | иначе Р7/PowerPoint предлагают «восстановить» файл | ✅ |
| `UNUSED_MEDIA` | в `ppt/media` нет файлов, на которые никто не ссылается | мусор + подозрение на повреждение | ✅ (пишутся только достижимые части) |
| `SLIDE_IDS` | sldId уникальны, у каждого есть слайд, разделы (`p14:sectionLst`) не ссылаются на удалённые слайды | битые разделы = окно восстановления | ✅ |
| `APP_PROPS` | `docProps/app.xml` — реальное число слайдов | в шаблоне там 28 слайдов и чужие заголовки | ✅ пересобирается; миниатюра шаблона удаляется |
| `SMARTART` / `MACRO` / `EMBEDDED_FONT` / `ANIMATION` | нет SmartArt, `vbaProject`, `embeddedFontLst`, анимаций | запрещено ТЗ/CLAUDE.md | ✅ не создаются; клон образца не берёт диаграммы/OLE |

Таблицы: только нативные `graphicFrame` + `a:tbl`, без `gridSpan/rowSpan/hMerge/vMerge`. Цвета стиля шаблона (`tableStyles.xml` + тема)
**прописаны в каждую ячейку явно**, `tableStyleId` сохранён — таблица выглядит одинаково, даже если Р7 не применит пользовательский стиль.
Проверяется в `tests/test_tables.py`.

## C. Известные риски (смотреть в первую очередь)
- Логотип в макетах `example_fields.pptx` — **EMF** (`ppt/media/image1.emf`): если Р7 на Astra не отрисует EMF, это картинка шаблона, не наша; сообщить организаторам/заменить в шаблоне на PNG.
- Встроенный стиль Office (`tableStyleId` без определения в `tableStyles.xml`) — цвета не разворачиваются явно, полагаемся на поддержку стиля в Р7. В обоих наших шаблонах такого нет.
- Подзаголовок титула в `example_fields.pptx` — TextBox (в макете нет `SUBTITLE_FIELD`), в Р7 редактируется как обычная надпись.
- Межстрочный интервал/переносы в Р7 могут отличаться от LibreOffice на 1–2 строки: Fitter оставляет запас 6% ширины; если на стенде видим переполнение — уменьшить `WIDTH_SAFETY` в `template/metrics.py`.

## D. Как пройти автоматическую часть руками
```bash
python -c "from deckgen.renderer.sanity import check_pptx; import sys; [print(p) for p in check_pptx(sys.argv[1])] or print('OK')" out/result.pptx
```
