# deckgen — ИИ-помощник: текст + корпоративный шаблон → редактируемый PPTX (Р7-Офис / Astra Linux)

Хакатон «ИИ-ассистенты для энергетики», полуфинал. Оценка: репрезентативность материалов (10) + качество/новизна реализации (10) + бизнес-ориентированность (10).
Жёсткие требования ТЗ: вход = текстовое описание + шаблон PPTX; выход = слайды с текстом и таблицами, значения не искажены, оформление по шаблону, PPTX открывается и редактируется в Р7-Офис (Astra Linux); модель заменяема без переделки решения; репо + инструкция запуска + примеры + описание возможностей/ограничений.

## Как работает команда (читать ОБЯЗАТЕЛЬНО перед любой правкой)
1. **Единственный источник правды по интерфейсам — `src/deckgen/contracts.py`.** Модули общаются только его типами. Нужен новый тип/поле → PR с префиксом `[CONTRACT]`, его одобряют все четверо. Без этого контракт не трогать.
2. **У каждой папки один владелец.** Править чужую папку нельзя: открой issue/сообщение владельцу или сделай PR, который он одобрит.

| Папка / файл | Владелец |
|---|---|
| `llm/`, `planner/`, `pipeline.py`, `cli.py`, `docs/PROMPTS.md`, `scripts/eval_models.py` | ML1 |
| `template/`, `fitter/`, `renderer/`, `templates/profiles/*.yaml` | ML2 |
| `api/`, `web/`, `Dockerfile`, `docker-compose.yml`, `validator/layout_*`, `scripts/render_preview.py` | FS |
| `ingest/`, `validator/fidelity.py` (совместно с ML1 по ревью), `data/`, `docs/` (кроме PROMPTS), `README.md` | BA |

3. **Ветки:** `main` всегда запускается. Работа в `feat/<роль>-<тема>`, PR в main, ревью — минимум один человек из смежной роли. Коммиты: `<модуль>: что сделано`.
4. **Definition of Done любой задачи:** код + тест `pytest` на моках, без падения `python -m deckgen.cli --demo`, обновлена строка в `docs/STATUS.md`.
5. **Не ходить мимо контракта:** нельзя передавать между модулями dict/строки вместо pydantic-типов, нельзя импортировать HTTP-клиент LLM вне `llm/base.py`.

## Технические инварианты (нарушать нельзя)
- Python ≥3.10, python-pptx, pydantic v2. Никаких Aspose/COM/MS Office-зависимостей. Должно работать на Astra Linux.
- Шрифт только Liberation Sans (есть в Astra, в корп. гайде ИнтерРАО). Кегли в PPTX задаются ЯВНО; **`normAutofit`/`spAutoFit` не использовать** (Р7 ведёт себя непредсказуемо).
- Нет SmartArt, макросов, внедрённых шрифтов, анимаций. Таблицы — нативные `graphicFrame` с `a:tbl`, не картинки.
- Выходной PPTX редактируем: текст в плейсхолдерах/текстбоксах, не в картинках. Пустые плейсхолдеры удаляются.
- **Числа и ячейки таблиц никогда не генерируются LLM, если они есть в источнике:** таблицы идут по `source_id`, подстановка делается Fitter-ом из `SourceTable` (строки как в источнике: "19,1", "≥ 10", "—").
- Каждое число в тексте слайда, полученное из прозы, сопровождается `Evidence.quote` — дословной цитатой; Validator ищет её в источнике.
- Любая LLM-проблема (невалидный JSON, таймаут) → repair-повтор, затем деградация (слайды из секций без LLM), но файл всегда создаётся.
- Модель, URL и ключ — только из env / `.env` (см. `.env.example`). Смена модели = смена переменных, код не меняется.

## Два режима шаблона (оба обязательны)
- `convention` — шаблон по README организаторов (`docs/TEMPLATE_README_from_organizers.md`): макеты `title*`, `section*`, `slide*`, `table*`, `last*`, плейсхолдеры `TITLE_FIELD`, `SUBTITLE_FIELD`, `TEXT_FIELD`, `IMAGE_FIELD`, `TABLE_FIELD`. Эталон: `templates/example_fields.pptx`. **Это главный путь — жюри, вероятно, подставит другой шаблон в этом формате.**
- `profile` — корпоративный шаблон ИнтерРАО (`templates/interrao_corporate.pptx`): в макетах только заголовок, остальное — свободные фигуры. Описывается YAML-профилем (`templates/profiles/interrao.yaml`): какой слайд-образец клонировать для title/section/slide/table/last, зоны текста/таблицы, стиль.
Определение режима автоматическое: есть макеты с именами из README → convention, иначе → profile (YAML рядом с шаблоном).

## Запуск (цель)
`pip install -e . && cp .env.example .env && python -m deckgen.cli --input data/samples/01_*.md --template templates/example_fields.pptx -o out/result.pptx`
`docker compose up` → веб-UI на :8000.
